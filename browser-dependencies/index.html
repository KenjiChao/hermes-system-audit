01 / BROWSER

已逐名清理 13 個，其餘 110 個保留。

先做 1 個試點，確認退出與其他程序不變後，再逐名處理 12 個。每次均重新核對固定程序身分、已結束的呼叫與上層工作、無在途 IPC 和瀏覽器斷線狀態，使用官方生命週期停止；沒有批次殺程序。

123 個是背景 daemon，不是 123 個 Chrome

約 66 秒的雙快照期間，全組未見可測 CPU time 增量或 IP 連線。這只表示觀察窗內暫時靜止，不能證明沒有待處理工作或未來重用需求。

來源可追溯，現行權屬仍不確定

已核對建立來源與歷史呼叫，但建立來源不是現行獨占擁有者。來源工作已結束，也不等於可以關閉；既有分頁、共用工作與遠端資源的保留需求仍待確認。

停止 13 個控制程序，沒有關閉使用者 Chrome

13 個目標均已退出，其 PID 與 socket 紀錄已移除；其餘 110 個 daemon、Chrome、cmux 與 Gateway 主程序身分均維持不變。被移除程序的 RSS 加總約 273 MiB，這不是精確可回收實體 RAM。沒有連接 Chrome 去關閉分頁，也未宣稱逐頁狀態已驗證。

判斷核心是目前的工作與資源權屬，不是程序年齡、父程序已退出，或建立來源已結案。

02 / DEPENDENCIES

7 個套件，風險要看前提。

132 個公共套件實掃，產生 13 筆「套件 × 公告」命中；httpx2 與 httpcore2 共用一項，因此去重為 12 項公告。

5 個套件的 lock 已含修復版，正式安裝卻仍舊；httpx2／httpcore2 則連 lock 都停在舊版。只看 lock 更新或依賴相容檢查通過，不能當成修補已部署。

03 / NEXT STEPS

處理順序與實際進度。

審核完成；修補尚未部署／限定範圍測試通過。已完成與尚待處理項目分開記錄。

  1. 七套件候選完成，其他 126 個套件不變

    正式環境、來源與設定已有私有備份。候選版本為 Click 8.4.2、httpx2／httpcore2 2.12.0、pydantic-settings 2.14.2、Pygments 2.20.0、PyNaCl 1.6.2、Tornado 6.5.8。Click 保留既有 lock 的版本，避免影響其他延遲安裝依賴；httpcore2 依 httpx2 metadata 成對升級。

  2. 隔離相容測試與真正回復演練通過

    主測試 207 通過、0 失敗、3 跳過；父代理從固定來源與核驗過 hash 的 wheels 離線重建，重跑結果一致。規格與品質複審均通過候選；另補上失敗即拒絕的父代理驗收器，12 項正負測試通過，不再把外層指令 exit 0 當成驗收。原基線有 1 項既有 OpenCC packaging 政策不一致，候選依既有 exact-pin 規則補齊，沒有改測試。候選 132 個公共套件複掃無已知公告命中；只升七包再退回原版的演練，133 個原版本完全恢復。這不是正式環境已修復。

  3. 正式部署卡在維護窗口，不是測試失敗

    不能在活躍 worker 使用同一個 venv 時替換套件，否則會混用新舊模組。Gateway 也禁止從自身內部停止或重啟。須由 Gateway 外的操作者建立無在途工作與無並行寫入的窗口，再套持久 patch、升級七包、重啟並驗 Telegram。沒有繞過保護、另造重啟排程或擅自中斷工作。

  4. 保留既有安全政策與已知相容性例外

    全局 14 天套件 aging 保留；OpenCC 仍精確固定原版本。PyNaCl 沿用既有 uv voice override，收緊至修復版下界；一般 pip 不會讀此 override。已驗離線 Discord 加密 API，不宣稱真實通話、全上游 suite 或所有平台功能已通過。

  5. 瀏覽器首輪清理完成，保留未確認權屬的其餘程序

    已用官方逐名停止方式完成 13 個已結案且斷線的目標，110 個保留。停止 daemon 不可復原原記憶體狀態；日後需要時由原工作正常建立新 daemon，不複製回舊 PID／socket。未新增排程，也未關閉使用者 Chrome 或 cmux。
